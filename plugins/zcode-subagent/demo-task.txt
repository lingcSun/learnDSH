背景:这是一个全新的演示项目。目录 D:\deepseek harness\zcode-demo 已存在,是本项目唯一允许写入的位置;你拥有该目录内的完整权限,严禁在该目录之外创建或修改任何文件。运行环境为 Windows,Node v24 已可用。无需初始化 git。

目标:用纯 Node.js 从零实现一个 Markdown 统计命令行工具 markstat。仅允许 Node 内置模块,严禁 npm install,严禁任何第三方依赖,最终项目里不得出现 node_modules 或 lock 文件。

功能要求(统计逻辑须对任意 UTF-8 Markdown 文本正确工作):
1. 总行数;字数统计需区分:中文字符数、英文单词数、数字串数量
2. 各级标题(ATX 形式 # 到 ######)数量,按级别分别统计
3. 围栏代码块(``` 与 ~~~ 两种)数量,以及按信息串标注语言的分布;无语言标注计入 plain
4. 链接统计:内联链接 [text](url)、图片 ![alt](src)、尖括号自动链接 <https://...>;并区分外链(http/https 开头)与相对路径链接
5. 任务列表项:- [ ] 与 - [x],分别统计未完成/已完成数量
6. 正确性关键点:代码块与行内代码内部的伪 Markdown 语法必须忽略——代码块里的 # 不算标题、里面的链接和任务列表不算数

CLI 要求:
- 入口为 node bin/markstat.js <文件路径...> [--json]
- 不带 --json 输出人类可读的缩进文本;带 --json 输出单个合法 JSON 对象
- 支持一次传多个文件:每个文件各一份统计,最后附 all 合计
- 文件不存在或扩展名不是 .md/.markdown 时,输出明确错误信息并以非零退出码结束

代码结构要求:
- src/parser.js 负责 Markdown 结构解析
- src/stats.js 负责统计计算
- bin/markstat.js 是 CLI 入口,负责参数解析、读文件、格式化输出
- 注释与 README 全部用中文

测试要求:
- 使用 Node 内置 node:test 与 node:assert,测试文件放在 test/ 目录,不少于 10 个用例
- 必须覆盖:标题统计、代码块与行内代码忽略逻辑、中英文与数字字数、链接与图片与自动链接、任务列表、多文件汇总、--json 输出可被解析、错误路径处理
- package.json 提供 npm test 脚本,实际执行 node --test

验收标准(全部满足才算完成):
1. 在项目目录运行 node --test,全部通过且退出码为 0
2. 项目内自建一个真实示例 .md 文件,运行 node bin/markstat.js 能正常输出;--json 输出可被 JSON.parse 解析
3. 项目内无 node_modules、无第三方依赖、无 lock 文件
4. README.md 包含功能说明与用法示例

完成后在最终回复中报告:创建的文件清单及各文件行数、node --test 的完整输出、一次真实 CLI 运行示例(含 --json 模式)、以及自查验收标准 1-4 的逐条结论。
